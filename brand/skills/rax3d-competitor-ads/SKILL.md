# RAX3D Competitor Ads Analysis

Adapted from Composio's Competitive Ads Extractor. Goal: learn what messaging and creative works for businesses similar to RAX3D (3D printing shop — customer sends a print file or picks from our pieces, Dammam, Instagram @rax3d.sa; niches coffee, automotive, tech, gifts, seasons) so our own ads and Reels convert better into DMs and orders.

Write the report in Arabic (Gulf-friendly), short and scannable.

## 1. Scope
- If the user names competitors or accounts, use them. Otherwise find 5–8 relevant ones: 3D printing shops and custom-gift / car-accessory / coffee-accessory sellers in Saudi Arabia and the Gulf, plus 1–2 strong international 3D-printing brands for benchmark.
- Default platform: Meta Ad Library (Facebook + Instagram, country: Saudi Arabia). Also look at their recent Instagram/TikTok Reels if ads are few.
- Use web search to find accounts; use a browser for the Ad Library when pages need rendering. Never log in to or act on the user's accounts.

## 2. Collect
For each ad/Reel: advertiser, platform, format (video/static/carousel), product, hook (first line / first 3 seconds), main message, offer, CTA, approximate run time (long-running ads usually perform), link if available. Save screenshots when possible. Keep a CSV of the collected rows.

## 3. Analyze
- Group by theme (personalization, gifts, price/discount, quality, speed, seasonal), by audience, and by format.
- Recurring hooks and visual patterns (timelapse of printing, before/after, unboxing, color options, customer reaction).
- What they emphasize that RAX3D doesn't, and gaps nobody covers (opportunity).
- Why the strongest ads likely work.

## 4. Report format
1. **نظرة عامة:** number of ads, competitors, dominant formats and CTAs.
2. **أقوى 5 إعلانات** with why each works.
3. **الأنماط المتكررة:** hooks, visuals, messages.
4. **الفرص الناقصة** RAX3D can own.
5. **توصيات لـ RAX3D:** 3–5 concrete ad/Reel ideas with hook + format, following the rax3d-brand rules (themed backgrounds, fixed slogan end card, "any color you choose", no prices).
6. Sources / links.

## Rules
- Research and inspiration only: never copy a competitor's copy, design, or footage.
- Never mention RAX3D prices; if competitors show prices, note it as a pattern only.
- Don't invent ad performance numbers; say when something is an estimate.
- Suggest repeating monthly to track how competitor messaging changes.
