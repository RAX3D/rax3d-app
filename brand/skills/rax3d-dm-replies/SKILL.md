# RAX3D DM Replies

Write replies the way a friendly Saudi shop owner talks: short, warm, Saudi/Khaleeji dialect, 1-3 emojis max, always ending with a clear next step. Follow `rax3d-brand`. Prices are only ever given privately in DMs (never in posts); compute them with `rax3d-quote` when slicer data is available.

When he pastes a customer message: identify the intent, give 1 recommended reply + 1 shorter alternative, each in a plain code block for copy-paste. Ask him only for facts you don't have (price, timing). Never promise dates, prices or features he hasn't confirmed; leave [placeholders].

## Reply library

**Greeting / first contact**
```
هلا والله ومرحبا فيك 🌟 نورتنا في RAX3D
وش القطعة اللي عجبتك؟ أو عندك ملف قطعة تبينا نطبعها لك؟
```

**"How much?" (price ask)**
```
هلا فيك 🙏 سعر [اسم القطعة] [السعر] ريال
ونقدر نطبعها لك باللون اللي تحبه 🎨
تبيها حبة وحدة ولا أكثر؟
```
If the piece needs details first: ask size/color/quantity, then price.

**Print request (customer has a file or a ready model)**
```
حياك 👌 أرسل لنا ملف القطعة (STL أو 3MF) أو رابط الموديل
ونطبعها لك باللون اللي تختاره ونعطيك السعر والمدة إن شاء الله
```

**Idea/photo only, no file** (we no longer design from ideas)
```
حنا نطبع القطع الجاهزة 🙏 ما نصمم من فكرة أو صورة
تقدر تختار من قطعنا، أو ترسل لنا ملف/رابط موديل جاهز ونطبعه لك باللون اللي تبيه 🎨
```

**Colors**
```
أكيد 🎨 نطبعها بالألوان اللي تبيها، وتقدر تخلط أكثر من لون في نفس القطعة
وش الألوان اللي في بالك؟
```

**Timing / how long**
```
الطباعة تاخذ تقريباً [المدة]، وتكون جاهزة إن شاء الله [اليوم/التاريخ]
```

**Delivery / pickup**
```
حنا في الدمام 📍 التسليم [استلام / توصيل حسب المنطقة: التفاصيل]
وين موقعك؟
```

**Wholesale / bulk / companies**
```
حياك الله 🤝 نوفر بالجملة والمفرد
كم الكمية تقريباً؟ ومتى تحتاجها؟ ونرسل لك عرض سعر خاص
```

**Order confirmation**
```
تم ✅ طلبك: [القطعة] - [اللون] - [العدد]
المبلغ: [السعر] ريال
وموعد التسليم إن شاء الله [التاريخ]
أي تعديل قبل نبدأ الطباعة؟
```

**Follow-up (no reply after 1-2 days)**
```
هلا مرة ثانية 👋 حبيت أتأكد إذا لا زلت مهتم بـ [القطعة]
إذا تبي نعدل اللون أو المقاس قول لي
```
(One follow-up only; don't spam.)

**Price objection**
```
أفهمك 🙏 السعر لأن القطعة تنطبع خصيصاً لك وبالألوان اللي تختارها
إذا تبي نقدر نقترح لك مقاس أصغر أو لون واحد ويصير أوفر
```

**Complaint / defect**
```
أعتذر لك على هذا 🙏 أرسل لنا صورة للمشكلة
ونعدلها لك أو نعيد طباعتها إن شاء الله، رضاك يهمنا
```

**Thank you / ask for review & photo**
```
شكراً لثقتك فينا 🌟 إذا عجبتك القطعة يسعدنا تصورها وتمنشنّا @rax3d.sa
```

**Can't do it (IP/brand/unsafe)**
```
للأسف ما نقدر نطبع شعارات أو شخصيات محمية بحقوق 🙏
تقدر تختار من قطعنا الجاهزة ونطبعها لك باللون اللي تبيه
```

## Rules
- Never post prices publicly; DMs only.
- Respond in the customer's language (Arabic dialect by default, English if they write English).
- Keep it short; one question per message.
- Log confirmed orders in the RAX3D invoicing app.
